
# Movie Industry Analysis

## Project Overview
This project analyzes 7,668 movies (1980–2020) to answer one key question:
**What drives box office success — budget, ratings, genre, or star power?**

## Tools Used
- Python (pandas, matplotlib, seaborn) — data analysis and visualization
- SQL (SQLite) — data querying

## Key Findings
1. **Animation and Family** films generate the highest average gross revenue
2. **Family and Thriller** genres deliver the best ROI
3. **Budget and gross** are positively correlated — but big budgets don't guarantee success
4. **IMDb score** has only a weak correlation with box office performance
5. **Steven Spielberg** is the highest-grossing director of all time
6. **Robert Downey Jr.** is the highest-grossing actor (driven by Marvel franchise)
7. Average box office revenue grew **5x** from 1990 to 2019
8. **Marvel Studios** leads all production companies in average gross revenue

## SQL Queries
- Average gross revenue by genre
- Top 10 highest-grossing movies of all time
- Best-performing movie in each genre (using CTE + JOIN)
